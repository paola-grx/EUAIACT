# AI primer: the basics in plain language

This short primer is included in your path because you told us you are new
to AI or to technical topics. It takes about 15 minutes.

## What is "AI"?

Think of an AI system as a very fast pattern matcher. It was shown a large
amount of example data and learned which outputs usually go with which
inputs. When you give it a new input, it produces the output that best fits
those learned patterns.

## Three kinds you will meet at work

- **Chat assistants** that write or summarise text for you.
- **Scoring or ranking tools** that sort cases, applications or risks.
- **Recognition tools** that read documents, speech or images.

## Key words

| Word | Meaning |
|---|---|
| Model | The learned pattern-matcher inside an AI system |
| Training data | The examples the model learned from |
| Prompt | What you type or give to a generative AI |
| Output | What the AI gives back: text, a score, a label |
| Hallucination | A confident but false output |

## The one thing to remember

AI output is a **suggestion**, not a fact. You decide what to do with it.
