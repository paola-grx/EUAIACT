# Article 4 AI literacy tool: demo

Demo of [paola-grx/EUAIACT](https://github.com/paola-grx/EUAIACT). It runs with fictional
sample data, and the data resets whenever the Space restarts.

**Open the app directly at `https://<your-user>-<space-name>.hf.space`.** For security, the
app refuses to be shown inside another page, so the preview on the Space page stays blank.

Do not enter real personal data.
